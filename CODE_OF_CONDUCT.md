# Code of Conduct

Branchlight is an open-source project. Be constructive, stay technical, and treat contributors with respect.

Harassment, personal attacks, discrimination, threats, doxxing, and deliberately disruptive behavior are not welcome in project spaces.

Disagreement about architecture, Git semantics, macOS behavior, or implementation details is normal. Argue the technical point, provide evidence, and leave the person out of it.

Project maintainers may remove content or restrict participation when behavior materially harms the project or its contributors.
